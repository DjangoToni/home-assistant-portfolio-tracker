# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Do not publish credentials, portfolio data, or exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, impact, reproduction steps, and a suggested mitigation when available.

Market-data provider outages, delayed quotes, and financial-data inaccuracies are reliability issues rather than security vulnerabilities and can be reported through GitHub Issues.
