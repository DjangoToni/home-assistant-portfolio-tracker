# Contributing

Contributions and focused bug reports are welcome.

## Bug reports

Please include:

- Home Assistant and Portfolio Tracker versions
- Asset type and symbol, with private transaction data removed
- Relevant `custom_components.portfolio_tracker` log entries
- Steps needed to reproduce the behavior

## Development

1. Fork and clone the repository.
2. Copy or link `custom_components/portfolio_tracker` into a Home Assistant development instance.
3. Keep changes focused and preserve existing config entries where possible.
4. Validate Python and JSON files and test dashboard changes on desktop and mobile widths.
5. Open a pull request describing the user-visible behavior and verification performed.

Do not include API credentials, personal holdings, transaction exports, or Home Assistant diagnostic archives containing private data.
